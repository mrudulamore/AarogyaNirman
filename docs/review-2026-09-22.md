# September 22 frontend review

Shared React changes apply to the website and Capacitor app source.

- Command Center keeps portfolio oversight; Field workspace keeps capture, progress and site actions.
- Physical/financial comparison and contractor progress share one panel. Contractor metrics derive from scoped projects.
- Pending work includes bill and control reviews, with direct links to the relevant project section and bill dialog.
- Role creation UI is removed; existing named roles can still be assigned.
- Project cards/details show completion countdowns. Completed projects do not show overdue countdowns.
- Project map marker selection stays on the map and zooms to the active tile layer's maximum (19).
- Finance pages use one ledger: dated verified payments are expenditure; dated verified receipts are government funding. Reversals remove the original transaction from current totals and appear as negative expenditure in their transaction month.
- The monthly bar chart displays the last 12 calendar months, including zero months and the partial current month, with month-over-month changes. Previous-month zero has no percentage delta.
- Pending liabilities include unpaid balances on partially settled bills and legacy PAID bills lacking a verified payment. Draft and rejected bills are not submitted liabilities. Sidebar, finance report and overview use this definition.
- Existing legacy receipt schedules remain plans until matched by a verified receipt reference. Their old received dates do not establish actual receipts.
- Project financial totals are reconciled on initialisation/restoration. No transactions are fabricated to reproduce old sample totals; fresh demo expenditure is therefore zero.
- Sample imagery now uses attributed Maharashtra construction photographs. Sample photo overlays explicitly identify illustrations and do not display fictional capture coordinates/timestamps over them. Device-captured evidence remains unchanged.
- Card text wraps, district finance charts are wider, and mobile charts scroll within their own container.

The last handwritten item ("the card") is incomplete and has no specific implementation.

Validation: production build, lint (existing warnings), finance-ledger/fund-report regression tests, project controls, site operations, report groups, role sessions, geotagging and localization; desktop/phone browser checks and bill deep link. No new APK or deployment is produced by this source push.
